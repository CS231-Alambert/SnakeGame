# 🐍 贪吃蛇大作战

经典贪吃蛇游戏，使用 Pygame 开发。支持鼠标操作、难度选择、玩家昵称和高分榜单。

## 功能特性

- 🎮 **经典玩法** — 方向键控制蛇移动，吃食物增长身体
- 🖱️ **鼠标操作** — 主菜单支持鼠标悬停和点击
- 📊 **难度选择** — 简单 / 普通 / 困难三档，影响初始速度和加速比例
- 🏆 **高分榜单** — 自动保存成绩，排行榜前 10 名
- 👤 **玩家昵称** — 输入昵称，成绩关联到个人
- 🎨 **中文界面** — 完整中文菜单和提示

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行游戏

```bash
python snake_trae_mouse.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| ⬆⬇⬅➡ | 控制蛇移动方向 |
| R | 游戏结束后重新开始 |
| Enter | 游戏结束后返回主菜单 |
| ESC | 返回上级菜单 |
| 鼠标左键 | 主菜单选择 |

## 游戏规则

1. 控制蛇吃到红色食物，每吃一个 +10 分
2. 蛇身会增长，速度会逐渐加快
3. 撞到墙壁或自己的尾巴 → 游戏结束
4. 游戏结束后自动保存成绩

## 难度设置

| 难度 | 初始速度 | 每次加速 |
|------|---------|---------|
| 简单 | 5 | +3% |
| 普通 | 8 | +5% |
| 困难 | 12 | +8% |
